## UI／視覺工作
- 任何會改變使用者所見內容的工作：先用 svg-ui-bridge skill 做成 SVG 或 HTML/CSS 設計稿（以 plugin 安裝時為 `/svg-ui-bridge:svg-ui-bridge`，上傳到帳號時為 `svg-ui-bridge`），在它的瀏覽器預覽中取得我的核准。只要求設計時就到此為止。我要求實作時，再逐元件實作並驗證（SVG 路線用 visual_diff）。有 superpowers 時，這在 brainstorming 的設計步驟之內進行，不是取代它。
- 視覺變更需求先改設計稿；`design/` 裡經核准的設計稿是外觀的唯一依據。
