## UI／視覺工作
- 任何會改變使用者所見內容的工作：先用 svg-ui-bridge skill 設計成 SVG 規格（以 plugin 安裝時為 `/svg-ui-bridge:svg-ui-bridge`，上傳到帳號時為 `svg-ui-bridge`），在它的瀏覽器預覽中取得我的核准，再逐元件實作，並用 visual_diff 證明。有 superpowers 時，這在 brainstorming 的設計步驟之內進行，不是取代它。
- 視覺變更需求先改 SVG；`design/` 裡的 SVG 是外觀的唯一依據。
